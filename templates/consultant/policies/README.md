# Lightweight policies

Five short policies, each about two pages once filled in. **A policy must describe what you actually do.** Edit them to match your practice, delete whatever does not apply, and review them yearly and whenever something material changes (control POL-01).

| Policy | Covers |
|---|---|
| [information-security.md](information-security.md) | Scope, roles, vulnerability targets, logging |
| [access-control.md](access-control.md) | MFA, least privilege, reviews, offboarding |
| [incident-response.md](incident-response.md) | Severity, response steps, notification decisions |
| [backup-disaster-recovery.md](backup-disaster-recovery.md) | Backups, restore tests, RTO/RPO, handling restored data |
| [vendor-management.md](vendor-management.md) | Vendor onboarding, DPAs, assurance review |
